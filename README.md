# 水下考古潜水记录 — 测线与浮标回收台

直接打开 `index.html` 使用（无需构建）。标记页已扩展为「测线与浮标回收台」，原标记列表、潜次时间线视图与 JSON 导出继续可用。

## 功能

- 标记：点击沉船平面图添加标记，可筛选（陶片/木构件/金属件/未知物）、编辑、删除，标记可关联到测线。
- 测线登记（右侧「测线回收台」）：测线号、两端基线点编号与坐标、布设测绘员、布设/回收时刻、两期流速、两期淤积、布设/回收浮标。平面图上实线为布设基线、虚线为回收基线；待复测红色、正常金色、旧版灰色。
- 自动判定（`js/judge.js`），命中任意一条即转入**待复测**：
  1. 回收时任一基线点坐标与布设偏差超过 0.5（平面百分比坐标）——两端坐标不一致；
  2. 回收淤积 ≥ 布设淤积 × 1.2——淤积较布设多两成；
  3. 回收浮标编号与布设浮标不同，或与其他在役测线的回收浮标重复——浮标串线。
- 复测：待复测测线由**另一名测绘员**（不得与布设人相同）确认并重设基线，系统生成新版本测线；原测线整体快照留档。
- 修订联动：关联标记自动改挂新版本测线，潜次按现行测线布设先后重排（旧潜次号→新潜次号记入留档）。
- 留档：右侧「旧版留档」列出每次修订的复测人、复测时刻、改挂标记数与潜次重排映射。

## 文件划分

| 文件 | 职责 |
| --- | --- |
| `js/judge.js` | 判定业务：坐标偏差、淤积增幅、浮标串线、复测校验、版本生成、潜次重排（纯函数） |
| `js/archive.js` | 存档业务：localStorage 读写、旧版快照留档、导出载荷；兼容旧版 `zfl30Marks` 数据迁移 |
| `js/page.js` | 页面业务：标记/测线表单、平面图测线绘制、列表与时间线视图、复测交互 |

## 导出与兼容

- 「导出JSON」仍下载 `dive-marks.json`，顶层 `marks` 数组格式不变（旧视图/读取方式可用），并扩展 `lines`（含判定状态与原因）和 `archive`（旧版留档）。
- 旧版单页存储键 `zfl30Marks` 中的历史标记会在首次打开时自动迁入新存储键 `zfl30SurveyStation`。
